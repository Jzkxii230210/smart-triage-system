# Smart Triage System · AI 辅助诊疗系统

## 1. 项目简介
**Smart Triage System** 是一套基于 Vue 3 生态构建的 AI 辅助医疗诊疗前端系统。

**核心定位**：以大语言模型为技术核心，面向基层门诊、社区医院、急诊分诊等场景，提供「智能问诊采集—辅助诊断参考—自动分级分诊—诊疗数据看板」全流程数字化能力，用于辅助医务人员提升接诊效率、规范问诊流程、优化诊疗决策。

**核心价值**：
- 通过 AI 自动完成症状采集与病史梳理，降低初诊问诊的人力成本
- 输出标准化的疑似诊断方向与分诊建议，减少人工判断偏差
- 全流程诊疗数据数字化留痕，支撑运营统计与质量分析

**核心亮点**：
- 🤖 **全链路 AI 辅助**：覆盖主诉采集、多轮追问、诊断参考、健康宣教完整诊疗流程
- ⚡ **极致开发体验**：基于 Vite 构建，实现瞬时服务启动与毫秒级热更新
- 🎨 **企业级交互**：深度集成 Element Plus 组件体系，界面规范统一，支持响应式适配
- 📊 **专业可视化**：内置 Apache ECharts，支撑多维度医疗数据可视化分析
- 🔌 **标准化接口**：统一封装 AI 服务接口，支持灵活接入不同大模型服务商

## 3. 核心功能

### 3.1 🤖 AI 辅助诊疗引擎
- **智能多轮问诊**：患者输入主诉后，AI 自动围绕症状部位、持续时间、伴随症状、既往病史等维度动态追问，完整采集病情信息
- **辅助诊断参考**：基于问诊信息输出疑似诊断列表、鉴别诊断方向与就医建议，为医务人员提供临床参考
- **健康宣教生成**：自动生成患者易懂的病情说明、日常护理与注意事项，支持 Markdown 格式富文本渲染
- **诊疗记录归档**：将问诊对话与诊断建议自动结构化存储，形成完整的电子诊疗记录

### 3.2 🏥 智能分诊与患者管理
- **自动分级分诊**：根据症状紧急程度与病情轻重，自动划分为「紧急」「优先」「普通」等级，优化就诊队列秩序
- **患者信息录入**：基于 Element Plus 表单体系，支持患者基础信息、过敏史、既往病史的快速录入与校验
- **实时候诊看板**：动态展示各科室候诊人数、平均等待时长、分诊等级分布，支持叫号与状态流转

### 3.3 📊 数据可视化与统计
- **诊疗数据总览**：多维度展示当日/月度接诊量、分诊分布、病种排行等核心指标
- **趋势分析图表**：基于 ECharts 实现就诊高峰趋势、病种变化趋势、科室负载情况等可视化分析
- **科室效率统计**：自动统计各科室、各医务人员的接诊效率与诊疗时长，支撑运营管理决策

### 3.4 ⚙️ 系统基础能力
- **多角色权限管理**：支持管理员、医生、护士等多角色权限配置
- **诊疗记录回溯**：支持按患者、时间、科室等维度检索历史诊疗记录
- **环境化配置**：通过 `.env` 文件灵活配置 AI 接口地址、API 密钥等环境参数

## 5. 快速开始

### 5.1 环境要求
- **Node.js**: `v16.0` 及以上版本
- **包管理器**: npm / yarn / pnpm
- **AI 服务**: 可接入的大模型 API 服务（需配置对应密钥）

### 5.2 安装部署

1. **克隆项目到本地**
```bash
git clone <your-repository-url>
cd smart-triage-system/frontend
```

2. **安装项目依赖**
```bash
npm install
```

3. **配置环境变量**
在 `.env` 文件中配置 AI 服务相关参数：
```env
# AI 服务配置
VITE_AI_API_BASE=https://api.example.com
VITE_SILICONFLOW_API_KEY=your_api_key_here

# 后端业务接口地址
VITE_API_BASE_URL=/api
```

### 5.3 启动与构建

- **启动本地开发服务器**
```bash
npm run dev
```
启动后访问终端输出的本地地址（默认 `http://localhost:3000`）即可进入系统。

- **构建生产环境包**
```bash
npm run build
```
构建产物将输出至 `dist` 目录，可直接部署至静态资源服务器。

## 8. 常见问题

**Q: 启动项目提示依赖缺失或 `vite: command not found`？**
A: 请确保已在 `frontend` 目录下执行 `npm install` 安装依赖；若仍有问题，可删除 `node_modules` 与 `package-lock.json` 后重新安装。

**Q: AI 接口无响应或返回错误？**
A: 请检查 `.env` 中的 API 地址与密钥是否正确，确认网络环境可正常访问 AI 服务，同时检查接口请求格式是否符合服务商规范。

**Q: ECharts 图表显示异常或尺寸错乱？**
A: 请确保图表挂载的 DOM 容器设置了明确的宽高；若页面尺寸变化，可监听 `resize` 事件并调用图表实例的 `resize()` 方法自适应。
